Verify before you trust

Every file has a SHA-256 in dist/SHA256SUMS.txt. Windows SmartScreen will warn on the unsigned installer — expected until code-signing lands. The in-app updater refuses any installer whose hash mismatches release/latest.json.

$ sha256sum -c SHA256SUMS.txt
Android  b0650a27e910ef6b0f1460b736d1a9f82448dfd0d5be4182b966ca544e287973
Windows setup  4cc7cdae091583811fe0000a736f20a82641f103b55798234816c91f19bf784e
Windows portable  0a325140a0c6e5dd29012958afcdb9024165385ff8f20d7199fddadff3e008b7

Android (store upload)

flutter build appbundle --release --obfuscate --split-debug-info=build/symbols

Upload the AAB with Play App Signing — the debug APK in dist/ is sideload-only.

Windows installer + auto-update manifest

$env:WINDOWS_CERT_PATH="C:\certs\khata.pfx"
scripts/build-windows-installer.sh   # -> dist/KhataCopilot-Setup-<ver>.exe + dist/latest.json

Needs Inno Setup 6 + a code-signing certificate.

macOS

scripts/build-macos-dmg.sh

Hardened runtime + notarytool notarisation on a Mac; mic/camera entitlements declared.

Linux / shareable test pack

flutter build linux --release
scripts/build-shareable.sh   # -> dist/ portable zip + APK + SHA256SUMS.txt
